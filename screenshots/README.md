# API response screenshots

Add genuine screenshots captured while running the included Postman collection. Recommended filenames:

- `01-registration-success.png`
- `02-login-token-success.png`
- `03-protected-route-success.png`
- `04-invalid-registration.png`
- `05-invalid-login.png`
- `06-missing-token.png`

Each screenshot should show the request name, HTTPS URL, response status, and response body. Do not capture `.env`, the JWT secret, or other private configuration.
